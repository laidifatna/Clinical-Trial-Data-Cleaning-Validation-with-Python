# Clinical-Trial-Data-Cleaning-Validation-with-Python
This project focuses on data cleaning and validation of publicly available clinical trial data before statistical analysis.

Objectives

The notebook focuses on:

- Importing and inspecting an Excel-based clinical dataset
- Handling a multi-row Excel header structure
- Standardizing variable names
- Recoding categorical variables
- Removing redundant information
- Validating participant identifiers
- Checking treatment groups and measurement time points
- Identifying duplicate records
- Assessing missing values
- Checking data types
- Identifying non-numeric values in quantitative variables
- Investigating negative measurements
- Identifying potential outliers
- Reviewing potential outliers across treatment groups
- Preparing the dataset for subsequent statistical analysis
